BetterBoard is installed from the Atlassian Marketplace in under two minutes. You need Jira administrator permissions to install new apps for your instance.

## Prerequisites

Before installing, confirm the following:

-   Jira Cloud instance (BetterBoard does not support Jira Server or Data Center)
-   Jira administrator permission (global "Administer Jira" permission)
-   A valid payment method on file with Atlassian (required even for free trials)

<NeutralCallout type="note">

BetterBoard is free during the 30 day trial. A payment method is required by Atlassian for all Marketplace apps — you won't be charged until the trial ends.

</NeutralCallout>

<a id="install-from-marketplace"></a>

## Install from the Atlassian Marketplace

The fastest way to install BetterBoard is directly from the Marketplace website:

1.  Go to [marketplace.atlassian.com](https://marketplace.atlassian.com/apps/4162439467) and search for "BetterBoard"
2.  Click **Try it free** on the BetterBoard listing
3.  Select your Jira Cloud site from the dropdown and click **Start free trial**
4.  Atlassian will install the app into your site — this takes about 30 seconds
5.  Once complete, click **Get started** or navigate to any Jira space

<a id="install-from-jira"></a>

## Install from inside Jira

Alternatively, install without leaving your Jira instance:

1.  In the top navigation, click **Apps** → **Find new apps**
2.  Search for "BetterBoard" in the marketplace search
3.  Click the BetterBoard listing, then click **Try it free**
4.  Follow the prompts to complete installation

<a id="after-install"></a>

## After installation

Once installed, BetterBoard is available in every Jira space:

1.  Open any Jira space
2.  In the horizontal navigation bar, click the **+** button at the far right
3.  Find and click **BetterBoard** in the list to open it

<NeutralCallout type="note">

Drag the BetterBoard link to any position in the horizontal navigation bar for easier access going forward.

</NeutralCallout>

## Troubleshooting

Most installation work items are straightforward to resolve. Here are the most common problems and their fixes.

<a id="installation-error"></a>

### Installation fails

If the installation fails with a payment error, verify that your Atlassian account has a valid payment method in the billing settings. Atlassian requires this even for free apps during trial periods. Navigate to **admin.atlassian.com** → **Billing** to add or update a payment method.

<a id="app-not-loading"></a>

### App not loading after install

If BetterBoard opens but shows a loading error, check these common causes:

-   **Expired session**: Refresh the page to get a fresh authentication token
-   **Permissions**: Confirm the user has at least Space Member access to the Jira space

<a id="not-visible"></a>

### BetterBoard not visible in sidebar

Only users with access to the Jira space can see BetterBoard in its sidebar. Check that the user has been added to the space under **Space Settings → Access**. Jira administrators can see BetterBoard in all spaces by default.
