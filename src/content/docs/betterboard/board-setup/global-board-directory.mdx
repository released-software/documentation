The global board directory gives you one place to find every BetterBoard view you can access across Jira. Search by board or space, then open the right board in a click.

## Overview

Use the directory when you know the board you need, but not where it lives. Boards are grouped by their Jira space, so it is easy to scan familiar teams, projects, or work areas and jump straight into the view you want.

Each space shows its avatar, name, and key. Each board row shows the board name and when it was last updated, helping you spot the right view before you open it.

## Opening the directory

You can reach the global board directory in two ways:

-   In Jira's global side navigation, choose **Apps** → **BetterBoard**
-   From any board view, press `G` then `A` to jump there immediately

You can also press `⌘K` / `Ctrl+K` and choose **Go to all views** from the command palette.

<a id="searching"></a>

## Searching boards

Use the search field to narrow the list by board name or space name. Results update as you type, so short fragments are usually enough.

Press `/` to jump back to search whenever you are on the directory page.

## Keyboard navigation

You can move through the directory without leaving the keyboard. Use the arrow keys to choose a board, then press Enter to open it.

<table><thead><tr><th>Key</th><th>Action</th></tr></thead><tbody><tr><td><code>↓</code> / <code>↑</code></td><td>Move highlight to the next or previous board</td></tr><tr><td><code>Enter</code></td><td>Open the highlighted board</td></tr><tr><td><code>/</code></td><td>Focus the search field</td></tr></tbody></table>

When you change your search, the highlight moves back to the first matching board.

<a id="creating-a-view"></a>

## Creating a new view from the directory

To add a board to a space, choose the **+** button beside that space name. BetterBoard will start a new board in that space.

From any board view, you can also press `N` then `V`, or choose **Create new view…** from the command palette.

## Last-updated tooltip

Each board shows when it was last updated. Hover over the time to see the exact date and time.

## FAQ

<a id="why-are-boards-still-refreshing"></a>

### Why does it say "Refreshing boards…"?

BetterBoard shows boards as soon as it finds them. If you see "Refreshing boards…", you can keep using the directory while the rest of your boards finish appearing.
