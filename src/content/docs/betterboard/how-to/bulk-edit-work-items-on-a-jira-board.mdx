Bulk editing in BetterBoard happens on the board, not in a separate wizard. Select the cards you want to change, then update the field.

## How to bulk edit work items

<Steps>
<ol class="betterboard-how-to-steps">
<li>
### Select the work items

Click the first card, then hold `Shift` and click the last card to select a range. Hold `⌘` on Mac or `Ctrl` on Windows to select non-adjacent cards.
</li>
<li>
### Update the field

Use the selection toolbar to change Assignee, Sprint, Status, Priority, Labels, or a custom field.
</li>
<li>
### Review the change

BetterBoard applies the change to every selected card immediately.
</li>
</ol>
</Steps>

See [Inline editing](/betterboard/work-faster/inline-editing/) for supported fields and bulk-editing behaviour.
