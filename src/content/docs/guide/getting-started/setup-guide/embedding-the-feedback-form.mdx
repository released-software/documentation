The form embed enables you to integrate a feedback form seamlessly into your app or website. Feedback from customers and stakeholders lands in the [inbox.md](/guide/product/feedback/inbox/ "mention") for easy triage.

<NeutralCallout type="caution">
To enable users to log in, you must add the domain's URL to the list of [trusted domains](/guide/product/administration/trusted-domains/). The URL must include the subdomain. For example `feedback.example.com`.
</NeutralCallout>

## Installation instructions

<Steps>
<ol>
<li>
### Copy the Form ID

[Copy the form ID](/guide/resources/how-tos/finding-the-channel-id/) for the embed form.
</li>

<li>
### Select how to display your form

<div align="left"><Figure src="/media/hub/Form-Settings-Dialog.png" alt="Form Settings Dialog" width={375} /></div>

The form can be shown inline, alongside the content where you embed it, or opened programatically.
</li>

<li>
### **Add the embed script**

Add the following code snippet to the `<head>` section of your site.

```html
<script src="https://embed.released.so/1/embed.js" defer></script>
```
</li>

<li>
### **Add the released-**&#x66;orm **element to your page**

Add the following code snippet to the `<body>` section of your site. Unlike the widget, the page content renders where you position the element. Ensure you replace the `FORM_ID` attribute.

```html
<released-form form-id="FORM_ID"></released-form>
```

To automatically authenticate users, you can [implement user verification](/guide/getting-started/setup-guide/implementing-user-verification/) and pass in the `auth-token` attribute.

```
<released-form form-id="FORM_ID" auth-token="AUTH_TOKEN"></released-form>
```
</li>
</ol>
</Steps>

## Open/Closing the dialog

You can open the form programmatically using the Hub API:

```javascript
// Open the feedback form
window.Released.show('form', 'your-form-id');

// Close the feedback form
window.Released.close('form', 'your-form-id');
```

Example with a button:

```jsx
const openFeedback = () => {
  window.Released?.show('form', 'your-form-id');
};

<button onClick={openFeedback}>
  Feedback
</button>
```
